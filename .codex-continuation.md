## Architectural decisions

- `CallId` lives in `mesh-core-backend`, avoiding a scripting/backend cycle;
  shell and backend share the same transport identity.
- Existing service payload ABI and command payloads remain unchanged.
- Coalesced older calls produce explicit `superseded` results rather than
  disappearing silently.
- Deadline/cancellation applies before synchronous Luau handler execution;
  hard interruption of a running handler is not safe and was deliberately not
  attempted.
- The shell currently creates IDs at service dispatch. The frontend proxy does
  not yet receive completion data, so this is a transport/debug increment, not
  completion of the full awaitable API.
