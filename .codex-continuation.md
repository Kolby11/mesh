## Architectural decisions

- Catalog authorization is module root plus relative path; graph sources do not
  use free-form path joins.
- Safe reads use descriptor-relative traversal with `O_NOFOLLOW`, and bounded
  reads happen before JSON parsing.
- Catalog preparation is isolated from shell execution on a named worker.
  Callers synchronously await the candidate, but read/parse/compile work is off
  the shell thread.
- Complete immutable candidates are committed atomically; failures retain the
  last-known-good snapshot.
- Missing localized values remain visible as `!!key`; diagnostics are stable
  per owner/key and retain provenance/revision context.
