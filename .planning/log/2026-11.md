# November 2026

## 2026-11-07 — Preserve sibling roots on source reload

Area: frontend runtime. Catalog updates replace each affected root runtime with
the new compilation, retaining the previous runtime if initialization fails.
The initiating root is not initialized twice, and a root can catch up after
missing an intermediate catalog generation.

without persisting each intermediate value; release commits it. Keyboard steps
also invoke the slider release handler, preserving keyboard access. The wider
theme and font latency work remains open; no end-to-end speedup was measured.

for removal. A regression covers key adoption by a root and child. The element
crate suite passed (345 tests; eight ignored).
