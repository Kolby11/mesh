# November 2026

## 2026-11-07 — Preserve sibling roots on source reload

Area: frontend runtime. Catalog updates replace each affected root runtime with
the new compilation, retaining the previous runtime if initialization fails.
The initiating root is not initialized twice, and a root can catch up after
missing an intermediate catalog generation.

## 2026-11-06 — Commit text-size slider on release

Area: Settings and slider input. Pointer movement updates the displayed size
without persisting each intermediate value; release commits it. Keyboard steps
also invoke the slider release handler, preserving keyboard access. The wider
theme and font latency work remains open; no end-to-end speedup was measured.

## 2026-11-06 — Retained layout key adoption

Area: UI element layout. Structural reconciliation creates a fresh Taffy node
when a previously unkeyed widget gains a key, instead of reusing a node slated
for removal. A regression covers key adoption by a root and child. The element
crate suite passed (345 tests; eight ignored).

## 2026-11-06 — scrollbar palette regression replay

area: retained rendering validation

The scrollbar palette regression passed no damage to the replay selector, which selects no commands even under the full-surface policy. Supplying the reported damage exercises the replay and verifies the new thumb color without a geometry change. The focused test passed. A two-thread renderer run reproduced the separate geometry work-count failure (369 passed, 1 failed, 17 ignored); global resource revision changes from concurrent tests can force the observed full rebuild. Isolation and the appearance-switch work remain open.

## 2026-11-06 — independent text and shell sizing

area: appearance settings and style resolution

Text size now scales typography independently; shell scale scales absolute UI lengths and composes with text size. Both use profile-aware settings transactions and have separate Appearance controls. Focused style inheritance, settings transaction and Settings command tests passed; shell compilation passed. Live shell, profile-switch, popup and accessibility verification remain in the backlog.

## 2026-11-06 — Isolate retained geometry workload from resource revisions

area: retained rendering validation

The geometry workload's sparse-work assertions raced the text cache test's process-wide resource revision change. Both now use the existing resource-state test lock; the ignored text revision profile uses it too. Three complete renderer library runs with two test threads each passed (371 passed, 17 ignored); the geometry and full-build parity assertions remain intact.

## 2026-11-06 — Wayland outbound backpressure

Area: presentation event loop. A full Wayland socket no longer fails presentation: the event loop requests writable readiness while requests remain queued and retries flushing when the connection can accept them. A socket-pair regression fills and drains a real Wayland connection; the focused regression and the 115-test presentation library suite passed.

## 2026-11-06 — AnyRender fixture compilation

Area: optional renderer tests. Removed a stray field outside the style initializer and restored the missing diagnostics variable in the input fixture. The six AnyRender adapter tests passed with `renderer-anyrender` enabled.

## 2026-11-07 — Backend storage deletion accounting

Lua storage deletions now recalculate the resident aggregate charge and restore the value if charging fails. A real Lua-table regression covers deletion and an absent key.

## 2026-11-07 — Compilation source identity

Frontend compilation records the exact root and imported source bytes it parsed, so later filesystem edits cannot make stale compiled content appear current. A regression changes an import before publication and verifies the mismatch.

## 2026-11-07 — LSP formatting indentation limit

Formatting rejects space indentation wider than 16 characters with an invalid-parameters response, preventing unbounded client-controlled allocation. Handler tests cover normal and extreme widths.

## 2026-11-07 — Glass shell localization

Glass bar status and workspace labels and glass widget weather and idle-media text use module catalogs, including accessibility labels. An integration regression exercises English and Slovak, weather states, and switching back.

## 2026-11-07 — Tray Unicode and seat cancellation

Tray metadata truncates at UTF-8 boundaries; a private D-Bus provider regression exercises two-, three-, and four-byte characters across the limit and repeated updates. Seat removal now cancels queued IME edits and keyboard-enter events alongside other keyboard events, with a regression preserving another seat’s events.

## 2026-11-07 — Prepared backdrop admission

Prepared backdrop images larger than the cache budget remain usable for painting but are not admitted or allowed to evict existing entries. A bounded-budget regression covers admission, oversized images, and normal eviction.

## 2026-11-07 — Network and power provider updates

NetworkManager duplicate SSIDs retain the connected access point, with deterministic selection otherwise. UPower refreshes relevant battery changes once per signal batch. Real Luau provider regressions cover duplicate ordering, battery signals, line power, and removal.

## 2026-11-07 — Shape geometry paint identity

Canonical paint identity includes shape geometry, so retained changes generate damage even when bounds stay fixed. Regressions cover shape variants, retained classification and signatures, and fresh-versus-retained pixels.

## 2026-11-07 — Translation message validation

Catalog validation rejects unmatched closing braces before and between placeholders as well as after them. A focused regression covers malformed positions and valid messages.

## 2026-11-07 — IME text invalidation

Commit-only and delete-only text input edits invalidate the rendered text even without a changing preedit or a handler. A painted-input regression covers Unicode edits and clean no-op edits.

## 2026-11-07 — LSP Unicode formatting and completion

Template formatting preserves Unicode text and attributes, and script and contract completion scan character boundaries safely. Focused regressions cover Unicode formatting, idempotence and complete and incomplete completion inputs.

## 2026-11-07 — Surface centering policy

Centering participates in normalized surface policy, patches, role diagnostics and geometry diffs. Fixed-height side rails reconfigure for center changes; tests also cover unaffected top and spanning rails.

## 2026-11-07 — Core translation fallback

Core point, argument-aware and bulk translations share the same precedence, including English as a last resort when excluded from the selected chain. A regression checks fallback and higher-priority overrides.

## 2026-11-07 — Missing focus transfer destination

Cross-surface focus transfer validates its destination before changing the source. A regression covers source focus, keyboard policy, restoration bookkeeping, and hide requests when the destination is missing.

## 2026-11-07 — Semantic shortcut diffs

Semantic snapshot diffs include keyboard shortcut additions, changes, and removals. A regression verifies both full and dirty snapshot capture and no-op parity.

## 2026-11-07 — Bounded shell IPC clients

The shell control socket reaps completed client tasks and limits concurrent clients to 64, leaving excess connections in the socket backlog until a slot opens. A real-socket regression covers idle saturation, recovery, repeated clients, and shutdown.

## 2026-11-07 — Service source generation guards

Equal service payloads advance their source identity and generation guard without notifying observers. A regression verifies stale updates are rejected while later valid updates still publish.

## 2026-11-07 — Lock verification errors

Module lock verification reports individual digest failures and exits unsuccessfully even when every digest fails. A regression covers valid, edited, missing and invalid module trees.

## 2026-11-07 — Executable dependency checks

Binary dependency availability uses the runtime executable-file permission rule for explicit paths and PATH search. Regressions cover non-executable files, directories and later executable PATH candidates.

## 2026-11-07 — Native control key protection

Shortcut override validation reserves configured button, toggle and slider keys, including modifiers matched by native handlers. Focused tests cover configuration changes and slider dispatch when an override conflicts.
