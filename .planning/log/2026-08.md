# August 2026

## 2026-08-01 — Typed component binding and popover channels

`working tree` · area: component composition

The compiler-to-shell boundary now carries public component values, per-prop
bindings, and `bind:this` in a typed `ComponentCompositionProps` record instead
of encoding binding metadata as `__mesh_binding_*` and `__mesh_bind_this`
attributes. Public prop projection no longer needs to identify and filter
reserved names, and component memo fingerprints include each typed channel.

Promoted-popover wrappers likewise carry a typed, copy-on-write authored-node
flag rather than `_mesh_promoted_popover`. The flag survives component memo
reuse and remains distinct from module-authored attributes. Embedded handler
targets still use the serialized `__mesh_embed__::` form and remain open in the
backlog.
