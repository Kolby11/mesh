# October 2026

## 2026-10-01 — Block review Priority 1: isolation and capability grants

`5dd71773`..`d5cb04fb` · area: scripting realm, module graph, capabilities, profiles

All six Priority 1 items from the
[2026-09-30 block review](../codebase/audits/2026-09-30-block-review/REPORT.md)
are fixed, one commit each, each with a regression test.

- **SH-01** (`5dd71773`). `commit_pending_profile_switch` now installs
  `ActivationPlan.effective_capabilities`, and `ActiveSnapshot` exposes them.
  Retained surfaces are re-prepared when a module present in both activations
  has a different grant. Running providers whose grant changed restart.
  Test: `committed_activation_replaces_the_previous_capability_grants`.
- **MOD-02** (`c897c9c8`). `TrustTier::for_source` no longer takes a module
  id: unsigned git is `community`, unsigned path is `local`. Unlocked modules
  under `@mesh/` stay `core` (`for_unlocked_module`), because install review
  and lock bookkeeping now reject git or path sources that claim the reserved
  scope (`check_installable_module_id`). Spec 01 §7 updated.
- **MOD-03** (`9c9d7749`). Every uninstall calls
  `RootModuleGraphManifest::forget_uninstalled_module`, which drops the
  module's approvals and `disabled` entry. The root is saved when that changes
  it, including for auto-discovered inventories. The forced path also saves
  now; before this it lost its reference cleanup when the inventory was
  implicit.
- **MOD-04** (`e803ade3`). An in-argument `*` matches only
  `[A-Za-z0-9._/@:+=-]`. `exec_argv_grant_error` rejects any wildcard for
  interpreters and launchers (`env`, `awk`, `python*`, …). For shells, the
  only wildcard it allows is a whole-argument `*` after an exact `-c` script.
  The Hyprland socket probe is now `sh -c 'test -S "$1" && echo ok' sh <path>`.
  Three test grants of `exec.argv:sh:*` became exact scripts. Spec 01 updated.
- **MOD-01** (`bcd6f2ff`). Provider priority no longer selects a contract.
  Identical inline copies share one declaration. Differing copies leave the
  interface undeclared and give every declarer a
  `conflicting_interface_declaration`. Interface modules still own their name.
  Spec 01 §4 updated. No shipped interface had more than one declarer.
- **RT-01** (`dbf8f068`, `d5cb04fb`). `getfenv`/`setfenv` are removed from
  realm globals before `sandbox(true)`. Template expressions are still
  closures inside the component chunk, so they keep the component's lexical
  locals. The host binds each closure's environment with
  `Function::set_environment` to a proxy that resolves call locals first and
  then records the member read.
  - The first attempt compiled each expression as its own chunk. That lost
    access to component locals and failed
    `template_expressions_use_component_lexical_scope_and_full_luau`, so it was
    replaced the same day.
  - Live `bind:this` function and table values are deep-wrapped by a Lua helper
    with an empty environment. Nested tables iterate through `__iter`;
    `pairs()` sees an empty proxy.
  - Frontend channel subscriber sets live in a locked metatable. Backend
    channels capture theirs in closures. `__subscribers` is no longer a field.
  - Test: `live_binding_values_cannot_reach_the_child_environment`.

**Validated.** Debug, `cargo test --workspace --no-fail-fast`, compared by
failure name against the pre-session sources (`3b5528b6`) checked out in place
with the same target dir. The two names that failed only after the change
(`phase98_pixel_equivalence_backend_update`,
`debug_snapshot_exposes_installed_module_graph_contracts`) pass standalone.
Two names failed only in the baseline, including the known-flaky
`thread_vm_reclaims_dropped_context_environments`. The other 49 failures are
the same in both runs. `target/debug/incremental` (16 GB) was cleared first:
the disk had 122 MB free, and that made file-writing tests fail.

## 2026-10-01 — Block review Priority 2: shell survival and bounded failure

`9518ebf7`..`03d263af` · area: effect scheduler, backend runtime, storage budget, run loop

- **SH-02** (`9518ebf7`). A failing effect no longer leaves `process_effects`
  with an error; that error used to stop the shell. It is recorded as a
  `shell_effect_failed` diagnostic for its source, and the function now
  returns the report directly. A core service call made inside the scheduler
  becomes a follow-up tagged with its call id and answers `queued`. The call
  is settled only when the request applies or fails. If the request started a
  durable control-plane or profile write, it is settled when that write's
  worker reports back. Durable writes that arrive while another is pending
  are parked by setting key: theme, mode, locale, icon theme, font, provider,
  enabled, prop. A later write to the same key supersedes the parked one and
  answers it. Parked writes re-enter the scheduler when the pending write
  completes. Effects that are dropped, discarded or purged answer their calls.
- **SH-03** (`9abea260`), scheduler half. `@mesh/shell` effects are deferred
  over budget but never counted toward quarantine. A source earns at most one
  violation per frame and loses one per frame within budget. Before this,
  every deferred effect counted, so one burst quarantined at once. Blocked
  causal chains are pruned with their transactions. Attribution of
  component-returned effects stays open in the backlog.
- **SH-12** (`d95fd0bd`). `retire_component` is the single removal path for
  profile replacement and frontend deactivation. It returns the unmount
  effects; profile replacement used to drop them. It purges the runtime's
  queued effects, call routes and popup grabs.
- **RT-03 / RT-05** (`11e607d8`). `PollFailed` became `CallbackFailed { stage }`.
  Stream callbacks share the poll rule: non-terminal until three consecutive
  failures. Backend events now use an awaited `send` on the bounded channel,
  so a full queue applies backpressure instead of ending the provider loop.
  The `Drop` path hands a terminal record to a task when the queue is full.
  The old test `bounded_event_sender_rejects_overflow_without_retaining_more_events`
  pinned the overflow-is-closed behavior and was replaced.
- **RT-02 / RT-10** (`db2b379e`). `recharge_storage(previous, next)` charges
  only growth against the aggregate budget. The per-document limit is still
  enforced by the storage manager. `ScriptContext` drop releases the
  side-effect budget of its queued events and element actions, and backend
  context drop drains its pending events.
- **SH-04** (`03d263af`). New flag `render_stalled`: a render pass that
  rendered a ready component and presented nothing. When it is set, ready
  render work waits for the next deadline, capped at 16 ms, instead of zero.
  The write-only `components_want_render` and `presented_last_frame` fields are
  deleted.
  - A first version keyed off any progress in the loop iteration. It broke
    `scheduler_wakes_for_visible_dirty_component_even_without_previous_present`,
    because a component dirtied after an idle iteration must still wake
    immediately. Narrowed the same day.
- `513b3f6d` removed an import that only test code used, which broke the
  scripting test build. Restored in `db2b379e`. Check with `--tests`.

**Validated.** Debug, `cargo test -p mesh-core-shell --lib` after each item,
compared by name against the Priority 1 baseline lists: no new failure names,
28 or 29 failures. `mesh-core-backend` passes 39 of 39. In
`mesh-core-scripting` the only failure is
`thread_vm_reclaims_dropped_context_environments`. Standalone it failed 1 of 3
runs, matching its flaky record.

## 2026-10-01 — Block review Priority 3, first batch

`386fe738`..`ee0df635` · area: CSS selectors, template dependencies, style cascade, input, exec, props

- **UI-01** (`386fe738`). `parse_selector` reads with
  `next_including_whitespace()`, so descendant and sibling combinators are now
  rejected; before, they lowered to a single compound. A selector error fails
  the whole stylesheet, so the shipped rules were rewritten first:
  - `volume-button`: icon fill and weight move to `.nav-button` state rules,
    which children inherit.
  - `view-tabs`: icon colour and weight move to the tab.
  - The inspector's transition reset lists its own tags.

  `style_diagnostics_descendant_selector_out_of_scope_documented` had pinned
  the old compound lowering and now asserts the rejection.
- **CMP-01** (`e61965d8`). This is conservative rather than precise tracking.
  An expression that reads a user-defined function is opaque: its value is not
  cached, and any public change affects the template. Host builtins such as
  `t()` are excluded. Templates that call helpers therefore rebuild on any
  public change. Not measured.
- **UI-02** (`65e3317f`). A node's cascade first applies the custom properties
  of every matching theme rule, component rule and inline style, then the other
  declarations. Matched rules are collected once, into the thread-local
  `MATCHED_RULE_SCRATCH`, and theme rules are matched once per pass. Not
  measured; the style-resolution benchmarks were not run.
- **UI-08** (`6b379590`). `is_editable_input_key` (input and not `readonly`)
  gates typing, IME commit, delete-surrounding, Backspace and Delete.
- **RES-07** (`5176be4f`). `mesh.exec` and `mesh.exec_stream` children get
  `LC_ALL=C.UTF-8`. The explicit env option stays in the backlog.
- **CMP-03** (`ee0df635`). Script-owned props are recorded in
  `script_owned_props` and stay owned until the script assigns `nil`.
  Detection still compares values, so an assignment equal to the current host
  value is indistinguishable from no assignment.

**Validated.** Debug with `CARGO_INCREMENTAL=0`; incremental caches filled the
disk twice this session. The elements, frontend, shell, theme and module
suites show no new failure names against the Priority 1 lists. Three
`shell::tests::scheduler` tests failed once in a multi-crate run: they read
global icon/glyph raster-job flags that other tests leave set. They pass
standalone (5 of 5).
