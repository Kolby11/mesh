# September 2026

## 2026-09-03 — Remove inert module locale setting

`working tree` · area: localization settings

The host-applied module default is the manifest metadata field
`mesh.i18n.defaultLocale`, which the installed module graph passes to the
shared locale catalog snapshot as the module's terminal fallback. The separate
per-module settings path `i18n.default_locale` had no host consumer; it was an
inert schema/example rather than a supported setting or locale override.

Removed that path from the shell-generated module schema, the shared module
settings field table, and LSP documentation/completion, and removed the stale
entry from `config/settings.json`. The surface resolver now diagnoses the path
as an unknown key without changing the manifest-derived surface layout.

**Verified.** The focused surface, shell-schema, LSP, and canonical locale
fallback regressions passed;
`mesh-core-surface-config` passed all 38 tests; `mesh-tools-lsp` passed all 116
unit tests, its manifest integration test, and its 6 settings integration
tests; and `nix develop -c cargo check --workspace` passed. The complete
`mesh-core-shell --lib` suite did not pass: 783 passed, 46 failed, and 132
were ignored. Those failures were existing renderer, interaction, debug,
lifecycle, profiling, and fixture failures outside this change.

## 2026-09-03 — Bound diagnostic history and debug export

Per module instance, diagnostic history now retains at most 256 records with
bounded issue-code, message, and source-path storage. Generated health
summaries are capped at 8 KiB, and the debug diagnostic projection is capped at
64 KiB per instance. Truncation and dropped records share the deterministic
`diagnostics:overflow` warning so the bound remains observable.

**Verified.** The diagnostics suite passed with 10 tests and 1 ignored; the
focused shell debug payload bound test passed. The full `mesh-core-shell --lib`
suite ran with 781 passed, 47 failed, and 132 ignored; its failures remain in
unrelated rendering, interaction, lifecycle, fixture, and profiling coverage.
`cargo fmt --all -- --check`, `git diff --check`, and
`nix develop -c cargo check --workspace` passed. An initial bound test exposed
that the health-status prefix was not included in the byte budget; the limit
was corrected before the passing run.
