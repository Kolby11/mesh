## 2026-07-28 — toolchain verified after linker note

area: build

Two backlog items recorded on 2026-07-28 that release measurement was "pending
because the local Rust linker wrapper is unavailable". Re-checked the same day
under `nix develop`, rustc/cargo 1.94.0: the release **test binary** builds,
links, and runs.

**Measured.** `shared_theme_defaults_beat_hashed_deep_clone` executes and
passes — 400,000 node resolutions, 35.8ms hashed lookup plus deep clone versus
19.96ms front cache plus shared defaults, `shared_theme_defaults_speedup`
= 1.79x.

That is **below the 1.84–1.98x range recorded when the checkpoint landed**. It
still passes the gate, and one run on a machine under other load is not enough
to call it a regression. Flagged rather than resolved: if a later run also lands
low, re-derive the recorded range instead of assuming the gate drifted.

The gates listed as pending in [`STATUS.md`](../STATUS.md) are therefore
unmeasured, not blocked.

## 2026-07-28 — style and composition checkpoints

`c00655ac` · area: style resolution, composition

Theme-default lowering now survives fresh `StyleResolver` construction: `Theme`
carries a monotonic style revision, and resolvers share a bounded thread-local
cache keyed by that revision, `(module_id, tag)`, and a collision-checked prop
snapshot. Indexed stylesheet declarations and theme-default maps pre-lower
static literals into typed colors, numbers, edges, corners, and dimensions;
`var()` / `prop()` values and all diagnostics deliberately retain the dynamic
string path.

Separately, the shared element IR took ownership of the embedded-handler and
component-prop wire protocol (`composition.rs`), replacing scattered magic
strings with typed constructors and constants.

**Measured.** Release, three runs of 100,000 fresh prop-bearing resolvers:
125.7–128.8ms repeated lowering versus 18.83–20.35ms through the revision cache
(6.18–6.84x). Representative 456-node tree build 0.416–0.424ms before versus
0.390–0.397ms after (1.05–1.09x end to end). Gated as
`shared_theme_defaults_speedup`.

**Left open.** Typed property values and one-time token lowering. Typed
declaration application has correctness parity coverage but its release
measurement and canonical gate were still pending at the time of the commit.

## 2026-07-28 — SHM buffers reused across content resizes

`56731a7f` · area: presentation

Wayland surfaces with `wp_viewporter` round physical SHM allocations up to 64px
size classes and crop to the rendered extent before applying the logical
destination. A six-frame content-size jitter sequence now keeps one pool
configuration instead of six. Compositors without a viewporter deliberately
retain exact-size allocations.

Newly allocated buffers begin with full visible damage, so a first sparse frame
cannot expose uninitialized pixels; the viewport crop uses post-`buffer_scale`
source coordinates, including fractional-scale frames.

**Measured.** Presentation suite: 55 passed, 12 ignored.
